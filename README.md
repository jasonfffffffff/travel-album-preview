# 沿途画册 · GitHub Pages 公开测试版

这是用于查看画册样式和测试国内网络访问的独立静态示例。所有风景 SVG 均为本项目自行绘制，不包含真实人物照片、姓名、私人日记、账户、密钥或真实关系日期；没有使用外部字体、图库、脚本、追踪或网络接口。

## 能做什么

- 响应手机和桌面屏幕。
- 按城市筛选五幅插画。
- 点击插画放大；使用关闭按钮、Esc 或点背景关闭，关闭后恢复焦点。
- 关闭 JavaScript 时仍可以阅读所有插画。

## 不包含什么

没有登录、上传、数据库、跨设备同步或私密访问保护。公开发布后，任何知道网址的人都能阅读，也可以查看源文件。`noindex` 只请求搜索引擎不收录，不是访问控制。不要把私人照片、日记、账户或密钥放入这个目录。

## 本机预览

在此目录运行：

```sh
python3 -m http.server 59410 --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:59410/>。这个回环地址仅供本机预览，不能发给另一部手机远程访问。

## GitHub Pages 发布

此项目不需要构建或安装依赖，也无需自行配置 GitHub Actions 工作流（Pages 会执行平台自带发布流程）。

1. 在自己的 GitHub 账户新建一个 **Public（公开）** 仓库，例如 `travel-album-preview`。GitHub Free 的 Pages 使用公开仓库。
2. 上传此目录中的 `index.html`、`styles.css`、`app.js`、`assets/`、`.nojekyll` 和此说明文件，放在 `main` 分支根目录。不要把外层文件夹整体作为网站根目录。
3. 在仓库 **Settings → Pages → Build and deployment** 选择 **Deploy from a branch**。
4. Branch 选择 **main**，目录选择 **/ (root)**，点击 Save。
5. 等待 GitHub 显示部署成功，再使用页面上实际返回的网址。一般为 `https://你的用户名.github.io/travel-album-preview/`。

所有资源引用都是相对路径，适配上述项目子路径，不需要自购域名。国内不同网络的可达性和速度需要实际测试；成功发布不代表两部手机都能稳定访问。

## 访问测试

两部手机分别用 Wi-Fi 和移动网络打开部署网址，检查首屏、五幅风景、城市筛选和放大。先测试再决定是否继续迁移正式画册。这个目录没有部署凭据，准备代码不等于已经上线。

## 文件

- `index.html`：完整页面、示例说明及大图对话框。
- `styles.css`：纸色与深绿视觉、桌面/手机布局、键盘焦点、减少动效偏好。
- `app.js`：城市筛选和原生对话框放大，无存储或网络请求。
- `assets/*.svg`：五幅自绘风景及小图标。
- `.nojekyll`：跳过 Jekyll 处理。

所有更改仅位于这个独立目录，原画册和服务器中的私人内容不受影响。
